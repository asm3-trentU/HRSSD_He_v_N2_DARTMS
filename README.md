This repository was created to explicitly share how we generate hi-resolution similarity score distributions (HRSSDs) and estimate medians (bootstrapping) in the article "Exploring the similarity of helium and nitrogen direct analysis in real-time mass spectrometry spectra" by Liggins, Moorthy and Davidson.

For convenience, we have coded up the example as a quarto document with code chunks. To run the file, simply open the quarto file in RStudio. Alternatively, you can see the results of running the file at this [link](https://asm3-trentU.github.io/HRSSD_He_v_N2_DARTMS/){target="_blank"}

This repository is maintained by Arun Moorthy. Please contact arunmoorthy@trentu.ca with any questions.

Note 1. The medians are estimated using bootstrapping with replacement (randomization) and so results may change slightly on each iteration.
