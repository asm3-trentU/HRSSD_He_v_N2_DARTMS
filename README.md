This repository was created to compute results and share code associated with the article "Exploring the similarity of helium and nitrogen direct analysis in real-time mass spectrometry spectra" by Liggins, Moorthy and Davidson.

This code base is maintained by Arun Moorthy. Please contact arunmoorthy@trentu.ca with any questions.

Note 1. The medians are estimated using bootstrapping with replacement (randomization) and so results may change slightly on each iteration.
